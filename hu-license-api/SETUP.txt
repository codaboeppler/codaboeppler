PASO 1: Crear cuenta en Vercel
================================================================================
1. Ve a vercel.com y crea cuenta (gratis)
2. Conecta tu repo de GitHub


PASO 2: Deploy del backend
================================================================================
1. En terminal:
   cd hu-license-api
   npm install
   npx vercel

2. Vercel te va a preguntar:
   - Link to existing project? -> No
   - Project name? -> hu-license-api
   - Directory? -> ./
   Sigue las instrucciones

3. Anota la URL que te da (ej: hu-license-api.vercel.app)


PASO 3: Configurar variables de entorno en Vercel
================================================================================
En Vercel Dashboard -> tu proyecto -> Settings -> Environment Variables:

   STRIPE_SECRET_KEY     = sk_live_XXXXXXX  (lo sacas de Stripe Dashboard > API keys)
   STRIPE_WEBHOOK_SECRET = whsec_XXXXXXX    (se genera en paso 4)
   STRIPE_PRICE_ID       = price_1THy9z08ioB1WxUXCbHNZIEu
   STRIPE_PRODUCT_ID     = prod_UGVAlNcICBrCkL

IMPORTANTE: Usa las keys de "Live mode", no "Test mode" para produccion


PASO 4: Configurar Webhook en Stripe
================================================================================
1. Ve a Stripe Dashboard > Developers > Webhooks
2. Click "Add endpoint"
3. URL: https://hu-license-api.vercel.app/api/webhook
4. Eventos a escuchar (selecciona estos):
   - checkout.session.completed
   - customer.subscription.deleted
   - customer.subscription.paused
   - invoice.payment_failed
5. Click "Add endpoint"
6. Copia el "Signing secret" (whsec_XXXX)
7. Pegalo en Vercel como STRIPE_WEBHOOK_SECRET
8. Redeploy en Vercel: npx vercel --prod


PASO 5: Actualizar URLs en el plugin de Figma

PASO 6: Actualizar success_url en checkout.js

2. Cambia las URLs de success_url y cancel_url por tu dominio real
3. Redeploy: npx vercel --prod

ARQUITECTURA
================================================================================

Flujo de compra:

   [Plugin Figma]
        |
        | POST /api/checkout
        v
   [Vercel Backend] -----> [Stripe Checkout]
                                  |
                                  | pago exitoso
                                  v
                           [Stripe Webhook]
                                  |
                                  | POST /api/webhook
                                  v
                           [Genera license key]
                           [Guarda en metadata de Stripe]
                                  |
                                  v
                           [Pagina /success]
                           [Muestra license key al usuario]


Flujo de validacion:

   [Plugin Figma]
        |
        | POST /api/validate { license_key }
        v
   [Vercel Backend]
        |
        | Busca subscription con esa key en metadata
        v
   [Stripe API]
        |
        | subscription.status === 'active'?
        v
   [Responde { valid: true/false }]


ENDPOINTS
================================================================================

POST /api/checkout        -> Crea sesion de Stripe Checkout
POST /api/webhook         -> Recibe eventos de Stripe
POST /api/validate        -> Valida license key
GET  /api/license?sid=X   -> Recupera license key post-compra
GET  /success?session_id= -> Pagina de exito (muestra la key)
